Términos de uso

Última actualización: 23 de noviembre de 2026

Mi Filmoteca es un proyecto personal, gratuito y sin fines comerciales para mantener una colección de películas vistas o pendientes. El acceso se ofrece sin garantía de disponibilidad permanente.

Uso de la aplicación

Cada usuario es responsable de su cuenta y de los registros que añade. No está permitido utilizar la aplicación para abusar del servicio, interferir con otras cuentas, intentar acceder a datos ajenos o realizar consultas automatizadas que sobrecarguen los proveedores.

Datos de películas

Los títulos, metadatos e imágenes pueden proceder de TMDB y estar sujetos a sus condiciones. This product uses the TMDB API but is not endorsed or certified by TMDB. Los datos de las películas pueden contener errores o cambiar.

Disponibilidad y cambios

El proyecto puede evolucionar, experimentar interrupciones o dejar de funcionar. Se recomienda conservar copias de información importante. El acceso está sujeto también a las políticas de los proveedores externos.

Privacidad y contacto

Lee nuestra Política de privacidad. Para consultas de asistencia o solicitudes relacionadas con una cuenta, utiliza el correo de contacto que aparece en la pantalla de consentimiento de Google. Para incidencias técnicas sin datos personales, utiliza GitHub Issues.
